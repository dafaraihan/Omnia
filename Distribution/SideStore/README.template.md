# Omnia for SideStore and AltStore

Installs for Omnia on iPhone and iPad. New versions appear in SideStore or AltStore after each release.

## Add the source

1. In SideStore or AltStore, open **Sources** and tap **+**.
2. Paste this link:

   ```
   {{SOURCE_URL}}
   ```

3. Install **Omnia**. It's signed with your own Apple account. A free account needs a refresh every 7 days, which the store app handles.

This repository holds only the source file and the app packages. Omnia hosts no content.
