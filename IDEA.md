Omnia is an early-stage native SwiftUI movie and TV discovery/player app for iPhone, iPad, and Mac: it uses a Supabase backend with PostgreSQL, Auth, Row Level Security, Realtime-ready tables, and a Deno Edge Function that securely aggregates and caches TMDB/TheTVDB metadata, while the app provides Home, Search, Discover, Library, Settings, rich title details, Stremio-compatible add-ons, and direct HTTPS playback through MPVKit. Its code is organized into App, Features, Domain, Data, Platform, and reusable UI layers, built as one Xcode target with Supabase Swift via Swift Package Manager.
